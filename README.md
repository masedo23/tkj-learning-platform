# TKJ Learning Platform

Platform pembelajaran berbasis web untuk siswa Teknik Komputer dan Jaringan (TKJ).

## 🚀 Fitur
- 📚 Materi per kelas (X, XI, XII)
- 🗂️ Roadmap pembelajaran terstruktur
- 📖 Accordion materi (tujuan, materi, latihan)
- 🎨 UI minimalis & responsive

## 🛠️ Teknologi
- HTML
- Tailwind CSS
- JavaScript
